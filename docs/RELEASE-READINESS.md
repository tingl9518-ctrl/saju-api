# Release readiness (현재 QA·문서·정책 기준)

본 문서는 **코드 변경 없이** 현재 저장소의 QA 결과·정책 문서를 종합해, **출시 관점**에서 범위를 나눈다.  
(상세 근거: `docs/qa-summary-milestone.md`, `docs/lichun-mismatch-nature.md`, `docs/yaja-policy-product-notes.md`, `docs/jieqi-strategy.md`, `reference/golden/README.md`.)

---

## 출시 가능 영역 (Release-ready)

| 영역 | 상태 |
|------|------|
| **일반 양력 케이스** | 생년월일·시각을 양력으로 넣는 **평범한 구간**에서 연·월·일·시 계산 파이프라인은 **안정적으로 동작**한다. 랜덤 QA 10건 중 **7건은 운세위키와 완전 일치**로 관찰되었다. |
| **대부분의 random QA** | 동일 요약: **절입 경계·자시 경계·특수 음력**이 아닌 샘플에서는 **위키와의 정합이 높다**는 결론이 문서화되어 있다. |
| **Regression / golden** | `npm test` **통과** 유지. 활성 골든으로 **회귀 고정**; 정책·번들 미정 케이스는 **`known_mismatch` 또는 `enabled:false`** 로 분리되어 **CI를 막지 않는다**. |

**요약:** “국내 만세력·운세위키와 **픽셀 단위 동일**”을 제품 약속으로 하지 않는 한, **MVP·베타 수준의 사주 네 기둥 API**로는 **출시 가능 영역이 넓다**고 본다.

---

## 미확정 정책 (Undecided)

| 항목 | 내용 |
|------|------|
| **야자시** | 운세위키는 적용/미적용 **사용자 선택**이 가능하다. 현재 엔진은 **일주 = 양력 달력 자정 기준**, 시진은 **한국형 30분 시진**이다. **제품 기본값·옵션 여부**는 미확정 (`docs/yaja-policy-product-notes.md`). |
| **Domestic reference bundle** | 절입·입춘은 **`bundle.json`**(lunar-javascript 생성 위주, 1997 등 일부 정합)에 의존한다. **국내 reference를 SoT로 한 번들** 전환 시점·범위는 미확정 (`docs/jieqi-strategy.md`, `docs/jieqi-data-pipeline.md`). |
| **윤달 일부 월주** | 번들 절입 vs 위키 월건이 어긋나는 케이스가 QA에서 **월주 mismatch**로 잡힌다. **윤달 + 절입** 조합은 **데이터 정합이 확정되기 전**에는 `known_mismatch` 등으로만 추적하는 것이 타당하다. |

## Blocker vs Optional improvement

### Blocker (출시를 **막는** 수준)

다음을 **동시에** 제품 약속으로 할 때만 **hard blocker**에 가깝다.

- “**모든 연도·모든 케이스**에서 운세위키(또는 특정 국내 만세력)와 **항상 동일한 네 기둥**”
- “**야자시**는 위키 기본 토글과 **무조건 동일**”
- “**윤달·입춘 근처**도 위키와 **수분 이내**”

위 약속 없이 **MVP / 내부 도구 / 베타(면책 문구 포함)** 이면, 아래는 **blocker가 아니라 리스크 + 로드맵**로 분류한다.

### Optional / 이후 개선 (출시 **후** 점진)

| 항목 | 성격 |
|------|------|
| **Domestic 절입 번들** | `jieqi-reference.csv` 축적 → 번들 재생성 파이프 → **정합도 상승**. 출시 후에도 **단계적으로** 가능. |
| **야자시 옵션** | UX·API 필드 추가·골든 분기. **정책 확정 뒤** 구현. |
| **윤달·입춘 골든 활성화** | `known_mismatch` 해소 후 활성 회귀 편입. |
| **CI에서 `qa:jieqi:report` FAIL 게이트** | domestic 번들이 기본이 된 뒤에도 늦춰질 수 있음. |

## “지금 출시한다면” 안내해야 할 제한사항

다음을 **제품 문구·API 문서·지원 FAQ** 등에 명시하는 것을 권장한다.

1. **만세력·타 서비스와의 차이**  
   연·월은 **절입 데이터(`bundle.json`)**에 따르며, **국내 상용 만세력·운세위키와 연도별로 다를 수 있다** (특히 **입춘 전후·윤달**).

2. **야자시(子時 일주 귀속)**  
   현재는 **양력 날짜 자정 기준 일주**와 **한국형 시진**을 사용한다. 위키의 **야자시 적용/미적용** 토글과 **완전 동일하지 않을 수 있으며**, 자정·자시 근처는 **별도 확인**이 필요하다.

3. **음력·윤달**  
   음력 변환은 `manseryeok` 등 **현재 스택**에 따른다. **윤달 월주**는 국내 표와의 정합이 **완전히 검증된 상태는 아니다**.

4. **해석(AI)**  
   API는 **OPENAI_API_KEY** 등에 따라 해석 기능이 **동작하지 않을 수 있다** — 이는 정책이 아니라 **운영 환경** 이슈.

5. **골든·회귀**  
   `known_mismatch`로 표시된 케이스는 **의도적으로 엔진과 기대값이 어긋난 채** 보관 중이며, **위키 기준 “정답”을 약속하지 않는다**.
